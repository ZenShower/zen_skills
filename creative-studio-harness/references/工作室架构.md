# 工作室架构

## 目标

创作工作室是一个长期运行的事实和决策系统，不只是素材文件夹。它需要让创作者知道：当前在做什么、为什么这样做、下一步是什么、哪些内容可以复用、哪些结论仍未验证。

## 中文工作空间分层

```text
创作工作室/
├── 00_创作中枢/              # 长期规则、工作台、事实源索引
├── 01_设定与生产资产库/       # 可跨项目复用的角色、场景、道具、声音和视觉资产
├── 02_灵感与选题池/           # 灵感、选题、系列和未立项提案
├── 03_内容生产/               # 每个项目的探索、脚本、分镜、执行、发布和复盘
├── 04_数据反馈与复盘/         # 平台快照、作品档案、实验和跨项目结论
├── 05_成品归档/               # 最终成片、封面、发布截图和交付包
├── 06_参考资料与输入/         # 原始散件、用户输入、外部资料和导入记录
└── 99_模板/                   # 可复制的工作文件和 Review 模板
```

## 三条信息流

1. **创作流**：灵感 → 选题 → 内容骨架 → 分镜 → 执行 → 发布。
2. **证据流**：原始输入 → 项目事实 → 平台快照 → 复盘结论。
3. **复用流**：项目产物 → 资产登记 → 下一项目调用；只有满足复用价值、稳定定义、提效或证据验证之一才进入资产库。

## 配置与项目的边界

`00_创作中枢` 记录跨项目规则；`03_内容生产/项目XXX_标题` 记录本项目的选择。项目可以临时覆盖节奏、时长或工具，但必须在项目文件写清覆盖范围和原因，不能静默改写长期规则。

## 最小运行状态

空间至少要有：工作室配置、事实源索引、工作台、一个内容形式策略、工具登记表和项目模板。内容配置可以是 v0.1；未确定部分标记为待确认。
