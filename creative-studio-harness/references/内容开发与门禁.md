# 内容开发与门禁

## 标准路径

```text
入口/灵感/反馈
  → 内容卡与观看承诺
  → 探索与方向发散
  → 内容骨架与角色/主体行动
  → 节拍、观看体验和风险预审
  → 脚本（需要时）
  → 分镜
```

## 内容卡至少回答

- 这条内容为什么值得看？
- 服务谁？
- 观众会观察什么、等待什么、得到什么回报？
- 主体的目标、行动和关系是什么？
- 自然开场在前几秒是否可读？
- 题材、内容线、形式和时长预算是什么？

## 预审要求

把骨架拆成连续节拍：触发、行动、可见变化、回应、回报和下一步期待。强节奏内容检查有效抓点的具体内容和间隔；治愈或知识内容按自己的观看承诺检查过程、信息或关系价值，不机械套用同一频率。

把风险和证据分开写。预测的观看吸引力是创作假设，不是真实留存率；不能先画高分曲线再为内容补理由。

## 通过标准

内容骨架至少有明确观看承诺、可理解的因果或信息推进、主体行动和结束方式。预审没有通过时，回到内容骨架或节拍设计；不要用漂亮分镜图绕过内容问题。

## 片头

除非项目配置明确要求，否则先完成自然正片和初剪，再根据真实素材决定是否提取前置片头。不要为预想中的片头提前制造重复素材。
