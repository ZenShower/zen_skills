# 工作室配置规范

`00_创作中枢/工作室配置.md` 是项目的可更新配置，不是一次性品牌宣言。它需要让另一个协作者在不知道历史聊天的情况下理解当前创作边界。

## 最小字段

```markdown
# 工作室配置

- 工作室名称：
- 配置版本：v0.1
- 最后确认时间：
- 一句话定位：
- 核心受众：
- 主要内容形式：
- 内容承诺：
- 时长与发布平台：
- 主体/角色/品牌：
- 视觉与叙事方向：
- 声音与音乐方向：
- 明确禁区：
- 当前可用工具：
- 待确认问题：
```

## 内容分类

配置时把以下概念分开记录：内容线、表达形式、题材、发布平台、项目阶段。比如“旅行”是题材，“Vlog”是表达形式，“强节奏短篇”是内容线，它们不能互相替代。

## 事实与假设

对每条长期规则标记来源：用户明确决定、已验证数据、项目经验、暂定偏好或待确认。没有证据的增长判断不能写成平台定律；没有用户确认的角色事实不能写成硬约束。

## 版本更新

重大变化追加版本记录，至少写：变更内容、来源、适用范围、为什么改、哪些旧项目不追溯重做。不要覆盖历史快照。
