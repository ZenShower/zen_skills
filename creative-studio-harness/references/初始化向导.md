# 初始化向导

## 先检查再写入

先确认目标路径、是否已有创作目录、是否已有规则文件、用户希望做的内容类型，以及是否允许创建文件。若路径存在，优先走已有空间接入，不把旧空间当成空目录重建。

## 最小配置问答

用少量问题完成第一版，不要求一次回答所有细节：

1. 你在创作什么？用一句话描述内容对象、主题或品牌。
2. 你希望谁看？他们为什么会点开并继续看？
3. 你准备主要做哪种内容：短视频、Vlog、剧情、知识、产品、播客、图文或其他？单条大致多长？
4. 观众看完应该获得什么：信息、情绪、陪伴、故事、行动或其他？
5. 你希望采用什么视觉、叙事和声音方式？当前明确不能出现什么？
6. 目前有哪些工具、账号或本地素材可以使用？哪些调用需要再次确认？

如果用户暂时答不全，写入已经确认的部分，其他写为“待确认”，不要阻塞整个空间建立。

## 写入顺序

1. 创建中文目录。
2. 写入 `00_创作中枢/工作室配置.md`，版本标为 `v0.1`。
3. 写入 `唯一事实源索引.md`、`工作台.md`、`内容形式与节奏策略.md`、`工具登记表.md`。
4. 写入 `初始化记录.md`，记录来源、确认项、暂定项和待补问题。
5. 创建 `99_模板/单项目生产模板/` 和 `03_内容生产/待孵化项目/`。
6. 运行 `validate_workspace.py`，报告缺失项。

## 不同创作类型的主体文件

- 固定角色或团队：`角色与主体关系总表.md`。
- 个人品牌：`创作者人设与表达边界.md`。
- 知识内容：`主题与观点框架.md`。
- 产品内容：`产品定位与使用场景.md`。
- 不确定时先使用 `主体与表达边界.md`，后续再细分。

## 初始化后的下一步

配置达到最小运行状态后，创建第一个项目。不要因为项目很小就强行补齐所有长期规则；项目中的明确决定可以先存在项目文件，成熟后再回写中枢。
