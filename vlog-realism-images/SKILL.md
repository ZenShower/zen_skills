# 真实 Vlog 分镜与生图

将场景或故事片段转化为可信的生活记录画面。真实感来自拍摄行为、人物行动、物理接触、光线和连续性，而不是堆叠“写实”“电影感”或人为瑕疵。

本文件包含完整方法、提示词模板与验收标准，不依赖其他文档、私有角色设定、指定模型或本地素材库。用户提供的参考图仅作为本次任务的输入。

## 1. 确定任务与输出

先判断用户需要分镜设计、可复制提示词、实际生图，还是已有图片的诊断与返修。遵循用户要求的交付范围；用户要求生成图片且环境有可用工具时，应实际生成，不以提示词代替结果。

优先使用已提供的场景、参考图、画幅、人物和动作信息。缺少的信息不影响结果时，采用合理假设并简要说明；仅在身份、画幅或关键动作确实无法确定时提问。

实际生图使用当前环境可用的图像生成或编辑工具，遵守工具的参考图输入要求。没有工具时，交付完整提示词并说明尚未生成；不要声称已完成图片或已通过视觉验收。

默认每张分镜图独立交付，不把多镜头拼成九宫格，除非用户要求图册或联系表。静态分镜图锁定某一动作状态，不假装一张图能够完成时间变化。

## 2. 先确定谁在记录

每张图设计前回答：

- 谁在拍？设备由谁持有，或由谁放置？
- 相机在哪里，以什么高度和朝向观察？
- 为什么此时会出现这个景别、裁切或遮挡？
- 谁知道镜头存在，谁继续自然行动？
- 光源在哪里？若出现模糊、过曝或偏斜，其原因是什么？

不能用“手机视角、自然光、Vlog 感”代替以上判断。写实材质与漂亮风景本身不足以建立记录感。

按活动选机位，不设置通用自拍比例或瑕疵配额：

| 记录方式 | 设备与位置 | 适合的画面 |
| --- | --- | --- |
| 前置自拍 | 手持手机、短自拍杆；位置符合持机者可达范围 | 贴近镜头说话、边走边记录；背景同伴继续行动 |
| 主观 POV | 胸前、头部或视线附近；明确固定方式 | 路线、操作、搬运；持机者通常不完整出现 |
| 同伴手持 | 同伴站在可抵达位置持机 | 追拍、回看、自然互动；取景跟随关注对象 |
| 临时固定 | 桌角、窗台、台面、背包支架等安全支点 | 料理、收拾、休息、待客；人物在画内继续生活 |
| 近距离细节 | 仍需说明由谁持机或固定在哪里 | 手、爪、工具、食物、接触点与质地变化 |
| 环境交代 | 有依据的远处固定机位或用户指定的航拍 | 少量交代空间、路线和距离，再回到参与者 |

固定观察不等于全知机位。居家与料理可以主要使用稳定的固定机位；不必为增加变化硬插自拍，也不必逐张表演架相机。

## 3. 根据观看需要设计构图

| 观看需要 | 构图选择 | 必须读清的内容 |
| --- | --- | --- |
| 像坐在参与者身边 | 桌边、床边或台面低位近景 | 面部状态、身体重量、手或爪与物体的接触 |
| 看懂关系与照顾 | 中景或中近景同框 | 双方视线、递出方向、接住空间与回应 |
| 参与做饭或手作 | 依据任务保留前景材料、中景操作和必要背景 | 材料状态、操作触点、结果变化与操作者反应 |
| 看懂旅行过程 | 自拍、POV、同伴记录与少量环境交代结合 | 行进方向、目的地线索、人物与环境的关系 |
| 捕捉自然趣味 | 动作与反应尽量同框，留出动作空间 | 注意到、犹豫、碰触、退让和对方回应 |

不要机械堆满前中后三层，不要求所有人物全身入镜。自然居中可以成立；避免为了对称让参与者停止行动、一起看镜头。

选择动作中具有信息的时刻：抬起、递出、接触、落稳、察觉或回应。松弛感不等于没有事件；小任务的进展、感官变化和互相回应就能支撑画面。

## 4. 真实感的五项联动

每张分镜把以下五项写成同一个场景的因果关系：

1. **设备与观察位置**：决定透视、高度、可见范围和前景遮挡。
2. **构图与接触可见性**：保留观众需要看懂的脸、手、爪、工具和作用点。
3. **正在发生的动作**：姿态有前因后果，重心、可达范围和物体支撑可信。
4. **光源与成像**：明确窗户、天空或室内灯的位置，以及曝光和景深取舍。
5. **前后状态连续性**：身份、服装、空间方向、道具归属和材料状态能够连接。

默认可采用普通手机录像截帧的观感，设备型号服从用户选择：

- 关系中景通常有较深景深，背景人物与环境仍可读；不要默认人像模式或电影级虚化。
- 真正靠近镜头的物体可自然失焦，近距离细节也允许景深变化，但不能模糊关键操作与回应。
- 窗光与室内灯产生有方向的明暗衰减；避免所有表面等亮、凭空轮廓金光和广告式布光。
- 运动模糊只出现在移动较快的部位，方向与动作一致；不要为“截帧感”添加全局失焦。
- 通过过曝和欠曝， 模拟真实的相机在强光比的条件的物理现象。
- 通过柔光和眩光， 模拟镜头在真实光照场景下可能出现的表现。
- 固定、干净、没有明显成像缺陷的画面同样可以真实。

以上在生成一张图的时候并不是全部采用， 而是基于图片所描述的场景， 组合、选择最合适的、最符合真实感的项目。

环境痕迹须与活动相关，例如用过的布巾、刚洗过的台面水滴、自然床褶。不要用满屋污迹、随机划伤或统一加噪替代真实生活。

人物与物体的接触必须成立：够得着、处于相容高度、握持或支撑方式可读。拟人动物保留既定身体结构，不自动长出人手。

## 5. 可选拍摄预设

按场景择一使用，也可依据物理条件调整；不要把所有预设叠加。

### 日间前置自拍

约 24–28mm 等效广角作为视觉参考，近大远小；允许帽檐、肩膀或边缘物体被自然裁切。背景同伴与环境可辨认，同伴不必看镜头。倾斜、晃动与高光溢出仅在持机和光照条件支持时出现。

### 逆光旅行自拍

天空、太阳或窗口在身后；测光优先保证脸部可读，亮天空可局部削顶。眩光、光晕或 HDR 边缘感按需要少量采用，不把全画面洗白。

### 夜间直闪抓拍

仅在明确使用闪光时采用：近处皮肤、毛发或衣料局部偏亮，背景迅速变暗，出现符合闪光方向的硬阴影与反光点。噪点按曝光条件决定，不用棚拍柔光均匀照亮远处。

### 动作中途截帧

选择未完成姿势，允许合理局部出框与前景遮挡；快速运动部分可有方向性模糊。焦点落点明确，主要动作仍可读；不追求商业运动摄影的完美凝固姿势。

### 固定生活观察

设备放在桌边、床边或台面安全位置，朝向当前工作与互动区域。依据任务选择近景或关系中景，保留交接空间、接触点和必要背景。稳定画面、自然居中、无明显瑕疵均可成立。

## 6. 参考图与系列分镜

生成前区分参考图的职责：人物身份、服装体型、空间布局、道具、构图，或拍摄质感。只继承用户指定或任务必需的属性；身份参考不意味着继承其棚拍光线、摆姿或精致度。

同一系列建立简短的一致性记录，直接放在当次输出中，无需外部文档：

- 人物：外观、服装、体型与可变表情。
- 空间：门窗、桌面、工作区、主要光源与朝向。
- 道具：位置、归属、数量与材料状态。
- 拍摄：画幅、设备观感与各机位位置。

相同机位不代表可以重复使用同一张图。材料质地、物体归属或人物反应变化时，根据需要补关键状态。先后图无法表达接触因果时，补接触态或临界态，而不是只增加无关角度。

场景母图也需落实设备观察位置、光源和生活状态，且与后续分镜相容。不要先做成明亮整齐的空间广告图，再期待人物图自行恢复记录感。

## 7. 生图提示词模板

每张图以完整自然语言描述一个确定状态；下面的字段用于组织信息，不要求生成工具理解字段名称。

```text
图片职责与画幅：
执行级分镜图 / 拍摄质感测试图 / 场景母图；画幅与用途。

参考图职责：
各参考图分别锁定哪些身份、服装、空间或道具属性。
没有参考图时，直接写清主体特征；不虚构已有素材。

场景与动作时刻：
真实空间、参与者关系，以及当前截取的是动作起点、接触态还是结果/反应态。
写清重心、接触与物体支撑，避免在一张图里要求完成连续动作。

记录方式：
谁在拍，设备由谁持有或放置在哪里，高度、朝向、景别与透视。

构图与人物关系：
前景保留什么，关键操作在哪里，谁看镜头，谁继续行动。
留出接触点、视线与动作所需空间。

光源与手机成像：
具体窗光或灯光来源、亮暗关系、焦点与背景可读性。
仅添加有原因的裁切、遮挡、局部模糊或高光溢出；可明确无明显缺陷。

连续性与后续用途：
必须保持的人物、服装、空间方向、道具归属与材料状态。
如用于视频，说明本图锁定哪个状态，后续动作另写在视频说明中。

排除项：
排除本场景实际容易出现的偏差，例如广告式布光、无理由浅景深、全员摆拍、
无来源的手持抖动、全局失焦、畸形接触、额外肢体或未经要求的文字水印。
```

避免默认堆叠 `8K`、`masterpiece`、`cinematic lighting`、`85mm`、`perfect composition`、`flawless`、`ultra-clean`、`studio quality`。这些词容易将画面推向商业样片。

不要仅靠负面词纠偏：先正面写出设备位置、光源、人物行动和景深，再补必要排除项。

## 8. 提示词示例

### 固定厨房观察：递碗接触态

```text
一张 16:9 横向生活 Vlog 分镜图，普通手机后置广角录像的截帧观感。
手机由做饭者放在餐桌靠墙一侧的低支架上，镜头略高于桌面，朝向厨房操作区。
做饭者站在画面左侧，将盛好的碗递向坐在右侧的同伴；截取同伴的手已经托住碗底、
做饭者尚未完全松手的一刻，双方受力与接触清楚，碗仍保持水平。
两人注意力落在碗与对方身上，没有看镜头。桌角在近处自然入画，不遮挡交接。
左侧窗户提供偏侧的日光，厨房较深处自然暗一些，室内灯只补亮操作台附近。
关系中景有较深景深，后方台面仍能辨认；只有贴近镜头的桌角略软。
桌上有刚使用过的布巾和少量与做饭有关的痕迹，其他区域干净。
画面稳定，无需倾斜、抖动或人为失焦；保持自然肤色与普通手机成像。
避免棚拍轮廓光、背景奶油虚化、整齐摆拍、悬空的碗和额外手指，不添加文字水印。
```

### 旅行自拍：同行者继续行动

```text
一张 9:16 竖向旅行 Vlog 分镜图。记录者停在步道较宽处，伸手持手机前置自拍，
等效约 26mm 的广角观感；面部靠近画面左侧，肩部自然被下边缘裁掉，透视符合臂长。
记录者刚转头看向身后的同伴，嘴角带着尚未收回的笑意。
同伴位于右后方，继续整理背包肩带，注意力在肩带上，没有为镜头站好。
步道和身后的坡面仍清楚可辨，构图保留同行关系与接下来的行进方向。
亮天空在两人身后，曝光优先保证近处面部，天空局部高光溢出但地面与衣服层次保留。
手机随手持姿势有轻微偏斜，不添加全局模糊、梦幻光晕或电影式背景虚化。
不出现第三方摄影机的视角，不为了展示手机而把持机者改成被别人拍摄，不添加文字水印。
```

## 9. 静态图与后续视频的边界

用户只要图片时，无需附加完整视频制作流程。用户需要后续视频时，分别交付图像状态与时间变化说明：

- Jump cut：同机位删去中间时间，分别定义跳切前后状态与不变锚点。
- 快动作：连续过程加速；慢动作：连续动作放慢。两者不能在单张静态图中直接实现。
- 局部抽帧：动作峰值出现间歇运动；定格：冻结画面；定格动画：逐格状态变化，三者需区分。
- 数码推近：裁切放大，不改变透视；若要相机前移，需另写设备运动。
- 遮挡转场：定义遮挡物、方向与遮满状态；静态图只承担对应边界状态。

避免在一张图片提示词中混入“先做 A 再做 B，最后切到 C”。互动的重要接触、材料变化与回应应在后续时间线中有完成空间。

## 10. 验收与返修

实际生成后查看图片再判断，不以提示词包含了某个词作为通过证据。

逐图检查：

- 能否指出拍摄者或固定支点，透视是否符合设备位置？
- 人物身份、服装、结构与关键道具是否一致？
- 行动是否自然，是否无理由地全员看镜头或停下来摆拍？
- 接触点、重心、支撑和可达范围是否成立？
- 光源、阴影、景深、遮挡与局部模糊是否有原因？
- 观众需要的操作、关系和环境是否读得清？
- 前后状态能否连接，物体数量、归属、材料状态和空间方向是否连续？
- 是否被美化成广告摄影，或被过量噪点、污迹与失焦破坏可读性？

发现问题时，先指出可观察的偏差，再改对应原因：

| 偏差 | 优先修改 |
| --- | --- |
| 像广告或样板间 | 明确实际光源、明暗衰减、普通手机景深和正在发生的动作，移除商业美化词 |
| 像刻意摆拍 | 调整视线、未完成动作和同伴自主行为，不用随机歪斜代替 |
| 太糊或太脏 | 移除无依据缺陷，恢复关键动作、面部与接触点的清晰度 |
| 物体悬空或接触失效 | 重设初始距离、高度、施力部位、支撑和当前动作状态 |
| 身份或空间漂移 | 明确参考图职责与不变锚点，减少互相冲突的要求 |

返修优先改少量关键变量，保留已经成立的身份和构图。不要只叠加“更真实、更自然”。如果所用工具支持编辑，可针对缺陷局部修订。

交付时提供图片或提示词，并简要说明所选机位与动作状态。有尚未解决的可见问题，直接说明；不要把静态图通过当作后续视频物理连续性已通过。
